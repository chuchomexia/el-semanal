# El Semanal — lanzador

Página mínima que se instala en el teléfono con el icono de El Semanal y abre la edición vigente en claude.ai.

- `index.html` redirige a la edición.
- `manifest.webmanifest` y los PNG dan el nombre y el icono al instalarla.
- `sw.js` existe solo para que Chrome ofrezca "Instalar".

La edición es un artifact privado: solo se abre con la sesión de claude.ai de su dueño.
